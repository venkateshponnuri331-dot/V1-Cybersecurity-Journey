# Day 2 - Computer Hardware Deep Dive

## What I Learned
- CPU (Central Processing Unit) is the brain of the computer.
- RAM (Random Access Memory) stores temporary data while programs are running.
- Storage (SSD/HDD) keeps data permanently.
- The Motherboard connects all computer components.
- The Power Supply Unit (PSU) provides electricity to every component.
- BIOS/UEFI starts the computer and checks the hardware before loading the operating system.

## Real-Life Scenario
When you press the power button on your laptop:
1. The PSU supplies power.
2. BIOS/UEFI checks the hardware.
3. The CPU starts processing instructions.
4. RAM temporarily stores running programs.
5. Windows loads from the SSD.
6. You can then open applications like Chrome or Microsoft Word.

# Day 3 - Windows Operating System

## What I Learned
- Windows is an operating system.
- It acts as a bridge between the user and computer hardware.
- Windows manages memory, files, devices, and applications.
- It provides a graphical user interface (GUI).
- Common versions include Windows 10 and Windows 11.

## Real-Life Scenario
When an employee turns on an office computer, Windows starts first. It allows them to open Microsoft Word, browse the internet, print documents, and connect to company networks. Without Windows, these tasks would be much harder.
